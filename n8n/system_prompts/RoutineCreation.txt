## PROTOCOLO DE SELECCION DE EJERCICIOS

### PASO 1: Analizar DAY REQUIREMENT
pattern: {{ $('Loop Over Items').item.json.pattern }}
min_sets: {{ $('Loop Over Items').item.json.min_sets }}
day_name: {{ $('Loop Over Items').item.json.day_name }}

### PASO 2: Seleccion Inteligente de AVAILABLE_EXERCISES

**Reglas de priorizacion (en orden):**

1. **EXCLUSION OBLIGATORIA** (Primero eliminar):
   - Ejercicios donde `main_muscle` este en la lista de musculos a EVITAR
   - Ejercicios cuyo `spanish_name` contenga terminos que el usuario rechazo
   - Ejercicios que violen las restricciones de salud

2. **PRIORIZACION POR MUSCULOS** (Preferir):
   - Si hay musculos prioritarios, PREFERIR ejercicios donde:
     - `main_muscle` coincide con la prioridad, O
     - `secondary_muscles` INCLUYE algun musculo prioritario
   - Esto permite trabajo indirecto del musculo prioritario

3. **ADAPTACION POR SEXO BIOLOGICO** (activa):
   - `F`: Priorizar ejercicios de Glutes, Hamstrings cuando el patron lo permita
   - `M`: Priorizar ejercicios de Chest, Back, Shoulders cuando el patron lo permita
   - Esto se aplica cuando hay multiples ejercicios validos para elegir

4. **ADAPTACION POR EXPERIENCIA**:
   - `beginner`:
     {{ $('ProcessUserPreferences').item.json.processed.home.is_home ? '- HOME: Priorizar bodyweight y mancuernas ligeras. Enfoque en forma y control antes que peso.' : '- GYM: Preferir `equipment` = "machine" o "bodyweight", evitar tecnicas complejas' }}
   - `intermediate`: Balance entre ejercicios disponibles
   - `advanced`:
     {{ $('ProcessUserPreferences').item.json.processed.home.is_home ? '- HOME: Maximizar intensidad con equipo disponible. Usar tecnicas avanzadas: tempo lento, isometricos, drop sets manuales.' : '- GYM: Priorizar compuestos con barbell/dumbbell' }}

5. **NIVEL DEL EJERCICIO**: Priorizar ejercicios con `level` = {{ $('ProcessUserPreferences').item.json.fitness_level }}

6. **REGLA DE VOLUMEN**: Si `min_sets` > 4, seleccionar 2+ ejercicios para distribuir series
